# 千纸课

一个轻量、无广告的 Android 课程表应用。

> 这是我的第一个 Flutter 项目，由 AI 辅助完成。  
> 目前仅适配了长沙理工大学教学一体化平台导出的课表格式。

## 功能

- 周视图课程表，左右滑动切换周次
- 课程组编辑——多门课程批量操作、冲突检测与弹窗提示
- CSV 课程表导入（支持 UTF-8 / GBK 编码，教务原始导出可直接导入）
- 教务在线导入——内置 WebView 登录教务，一键提取课表，免转 CSV
- 记住教务账号密码——多账号 Keystore 加密存储、手动一键填充（验证码仍需手输）
- 自定义背景——弥散圆形拖拽调色、图片双指缩放定位
- 课前提醒通知，基于定时器轮询 + 前台服务保活
- 前台服务保活，适配 vivo、OPPO/一加、小米/Redmi 的省电机制

## 重要：电源管理与后台保活

千纸课的课前通知依赖定时轮询和前台服务保活。  
国产手机对后台应用有严格的省电管控，**如果跳过以下设置，上课提醒极有可能延迟或彻底静默**。

> 提示：看到「流转」常驻通知时，说明前台服务已成功启动、后台保活正常。

#### 所有手机通用

1. 系统「设置」→「应用」→「千纸课」→「电池 / 省电策略」→ **无限制**
2. 同一页面 →「通知」→ 全部开启（至少保留「课程提醒」和「上课常驻」）

## 课表导入

支持两种导入方式，入口在「设置」→「课程表导课」：

### 教务在线导入（推荐）

1. 「设置」→「课程表导课」→ 选「**教务在线导入**」，内置浏览器打开教学一体化平台登录页
2. 输入账号、密码和**验证码**登录（验证码必须手动输入）
3. 进入「学期理论课表」页
4. 点底部「**导入课表**」按钮 → 自动提取并进入预览确认

**底部按钮说明**：

| 按钮 | 作用 |
|---|---|
| 「账密：0135」 | 显示所选账号后四位；点击展开已保存的账密列表（点账号=选中，垃圾桶图标=删除） |
| 「填充」 | 把选中的账密填入登录表单（验证码仍需手输） |
| 「导入课表」 | 提取当前课表进预览 |

**保存账密（多账号）**：

1. 右上角打开「**保存**」开关——登录成功跳转后自动加密保存账密（Keystore 加密，仅存本机）
2. 支持保存多个账号（自己/同学的）：同一账号重复登录自动覆盖密码
3. 保存的账号、选中状态、开关状态下次进入自动保持
4. 删除账号：点「账密：0135」展开列表，点右侧删除图标

**其他**：

- 内置浏览器适配桌面版网站（桌面 UA + 双指缩放），顶部 ↶ 为网页后退（登录后点击会退回登录页）
- 提示弹窗为浅色卡片式，0.75 秒自动消失，不遮挡底部按钮

### 从教学一体化平台获取 CSV

1. 登录长沙理工大学教学一体化平台
2. 进入「学期理论课表」，选择当前学期
3. 导出 Excel（`.xls` 文件）
4. 用 Excel / WPS 打开 → 另存为 **CSV（逗号分隔）**（编码 UTF-8 或 GBK 均可；教务平台原始导出的 GBK 文件可直接导入，无需转码）

### 导入前设置

- 先设置「学期第一天」：开学第一天（不必是周一，系统会自动计算）
- 这个日期用于计算每节课所在的星期序号，设错了提醒时间会错位

### 导入后核对

- 课程表页面左右滑动，检查四周课程是否完整
- 同一时段有冲突课程会弹窗提醒，可手动编辑调整
- 在「设置」中可修改提醒提前量（默认 15 分钟）

## 自定义背景

千纸课可以自由更换课程表页面的背景，入口在「设置」→「自定义」。

### 存档管理

- 点击「+」新建存档 → 选择「弥散圆形」或「背景图片」
- 点击任意存档卡片直接启用，蓝色边框和「使用中」标签标识当前存档
- 编辑和删除按钮始终可见，无需长按展开

### 弥散圆形编辑器

- 在手机比例的预览画布上**拖拽**圆形调整位置，**点击**选中，**长按拖动**
- 选中圆形后可以换颜色、调大小，也可删除（至少保留一个）
- 点击「添加圆形」可叠加多个不同颜色的弥散光斑
- 顶部标题直接点击即可重命名存档

### 背景图片编辑器

- 取景窗比例为手机屏幕比例（9 : 19.5），**框内所见即最终效果**
- 支持**双指缩放**和**拖动平移**精细调节图片位置
- 初次进入编辑器时图片为空，点击「导入图片」从相册选择
- 重置恢复图片初始大小和位置，移除则清空图片
- 没有导入图片就离开时会弹出提醒，防止空存档
- 顶部标题直接点击即可重命名存档

> 自定义背景保存后对所有页面生效（课程表、设置、导入等）。

## 技术栈

| 层 | 技术 |
|---|---|
| UI | Flutter (Dart) |
| 状态管理 | Provider |
| 持久化 | SharedPreferences |
| 在线导入 | WebView (webview_flutter) |
| 凭证存储 | flutter_secure_storage (Keystore 加密) |
| 原生通知 | 定时器轮询 + Foreground Service |
| 前台服务 | Android Foreground Service (specialUse) |
| 字体 | Google Fonts — Inter / Outfit |

## 构建

```bash
cd course_schedule_app
flutter pub get
flutter build apk --release --split-per-abi
```

安装 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`。

## 运行环境

- Flutter ≥ 3.5.0
- Android ≥ 8.0（API 26）
- 需要授予通知权限（应用内动态申请）
